## 已确认配置与实施规则

- 沿用后台当前价格 10 积分 / 次，当前数据库文本服务及默认模型。每人同时 1 个任务。
- 文案成果上限和容量预留为 8 MiB，匹配适配器既有上限。沿用账户 100 MiB、服务器 1 GiB 配额和既有容量预留规则，不调整上传与注册政策。

- 收费确认后受理并冻结；完整正文、文件、作品与最终消息持久化后消费；确定失败才释放。提交响应未知、查单暂时失败或保存异常不自动再次生成、不自动退还或消费。
- 已有上游记录时只查原记录、恢复原成果；没有记录且受理不明时待核查。在途素材保留引用。停用账户后的既有任务沿用原任务恢复，不改变权限政策。
- 核查责任为当前会话所属的现有管理员。24 小时为运营提醒阈值，不是失败或退款期限；仅启用既有恢复原任务、凭上游失败证据确认失败操作，不开启人工直接扣款。迟到冲突进入异常记录，已释放后不自动补扣。
- 文本源仅允许 `text-agent-v1:bound-record`；每个 / 每次下载最大 8 MiB、超时 30 秒、零重定向。它是同一绑定记录的受控正文读取，不是任意 URL 下载授权。

## 本机重启

本轮保留 API 和 Worker 后台运行。系统或进程重新启动时，需从 backend 目录重新启动它们，二者读取同一 `.env`：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:application --factory --host 127.0.0.1 --port 18000
.\.venv\Scripts\python.exe -m worker.main --stream TEST_ONLY:local-text:20261016 --group local-generation-workers
```

运行日志在忽略目录 `.local-data/api-local-generation.*.log` 与 `.local-data/worker-local-generation.*.log`。不会在启动时重复调用已完成的生成任务。

本机启用和验证不代表图片、视频或生产发布验收。
