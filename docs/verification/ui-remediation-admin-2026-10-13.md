# 后台界面整改记录

日期：2026-10-13。实施者 A；本文件是有限实施与自检记录，待主控独立复核，不代表全部原型一致、用户视觉验收或生产可用。

## 实施范围

已读取本轮整改手册、product-design、V2 暖色规范、终稿后台及权限/积分要求、当前范围及开发计划 T19/T20。原型依据为 `docs/prototype/admin.js` 和 `app.js`，通过 Chrome 实际访问原型八模块并打开任务、用户、发积分、Agent、规格和官网抽屉。

| 模块 | 源码 | 本轮变化 |
| --- | --- | --- |
| 任务与异常 | TasksView.vue | 移出用量统计；保留状态与用户筛选、诊断抽屉、独立内容授权、原任务核查；诊断码与处置名称中文化，补充已有耗时和核查截止时间 |
| 用户管理 | UsersView.vue 默认 users | 独立标题和列表；用户详情展示真实账号、昵称、角色、状态、注册时间及账本；保留账户状态政策/CAS确认 |
| 积分管理 | CreditsView.vue → UsersView.vue mode=credits | 接收用户选择、发放入口、目标账本及注册赠送配置；流水详情改为只读抽屉与中文字段 |
| Agent 配置 | AgentsView.vue 默认 agents | 独立服务列表，类型、环境和测试状态中文化；现有版本编辑抽屉和确认保留 |
| 规格与价格 | SpecsView.vue → AgentsView.vue mode=specs，内嵌 PricesView.vue | 同页展示参数默认值、规格/价格版本和积分；保留分别发布规格与价格及各自 CAS |
| 用量统计 | UsageView.vue | 独立调用真实 statistics；成功率保留服务端成功/终态口径，未知成本不补值 |
| 官网内容 | SiteView.vue | 原有介绍编辑与案例授权流程保留；本轮验证入口、抽屉及手机展示，未更改业务实现 |
| 操作日志 | AuditView.vue | 常见动作中文选择，保留其他类型标识查询；变更记录改为字段列表，原始未知键保留以免丢失证据 |

路由和导航由主控维护；本实施者未修改 router、shell 或 tokens。`admin.css` 仅修复后台隐式网格列被表格最小宽撑大的问题，表格在自身区域横向滚动并可键盘聚焦。

## 尚未符合原型的项目

以下未决项未擅自实现新业务或写入演示字段。需要接口/政策或用户改造计划，不能将本次交付称为全量严格对齐。

| 编号 | 原型位置与要求 | 真实约束与当前呈现 | 影响 / 待处理 |
| --- | --- | --- | --- |
| A-01 | usersView/userForm：关键词、店铺、联系人、邮箱、最近登录、任务数、列表余额 | AdminUserView 只有账号、昵称、角色、状态、注册时间及 auth_version；listUsers 只支持状态/cursor | 不伪造字段、不对已加载页冒充全局搜索；需 DTO 与查询能力 |
| A-02 | 新增、编辑、重置密码、删除用户 | 现有 API 只有账户状态写入；恢复/删除还涉及 D-07/D-09 | 未增加不可提交的按钮；需真实接口与明确政策 |
| A-03 | creditsView：全站流水、账号/原因搜索、总可用/冻结 | 只有指定用户账户与流水；LedgerEntryView 不提供操作人 | 当前按接收用户查账，未用审计充当账本，未把单页合计当平台总额；需聚合/搜索接口 |
| A-04 | users 与 credits 分离 | 为兼容现有已验证安全入口，用户详情仍有发积分/注册赠送快捷操作，积分模块另有独立入口 | 八模块结构已恢复，部分快捷操作并存；尚非逐按钮完全一致 |
| A-05 | agent-edit：地址、接入版本、状态、原因的简表 | 服务端读取故意不返 endpoint/secret_ref；写入新版本要求协议、输入约束、政策等 | 不回填脱敏值，不展示完整凭据；原有契约编辑保留，政策 JSON 收入折叠区域；简表替代正式契约需计划 |
| A-06 | spec-edit：规格/参数/价格同一次发布 | specs 与 prices 是独立版本接口，参数 schema 有类型、必填、选项、边界和组合约束 | 同模块分开编辑发布，不能伪造原子保存；规则/组合 JSON 暂保留在折叠区，尚未与原型平面参数编辑一致 |
| A-07 | tasksView：任务/用户关键词、Agent 筛选、固定费用、会话、外部/上游标识、作品/保存记录、时间线 | listTasks 只有 state/user_id/cursor；TaskDiagnosticView 不含这些私有/提交快照字段 | 当前只展示真实诊断数据；不能绕独立内容授权取正文或把常规后台权限扩大 |
| A-08 | usageView：按 Agent 汇总、状态分布、未结算及成功/全部任务 | StatisticsView 无分组/状态分布，success_rate 明确为 succeeded/(succeeded+failed+manually_closed) | 保留真实终态分母，不改统计口径；缺失指标明确不可用，需接口与口径决策 |
| A-09 | logsView：对象/操作人/原因统一关键词 | listAudit 只有 action/actor_id/object_id/cursor | 保留精确筛选，尚无原因关键词；未知动作或变更键仍保留原标识，避免错误翻译或隐藏记录 |
| A-10 | site-edit：仅介绍简表 | 当前真实保存包含介绍、三 Agent 文案、流程及公开政策，案例需独立公开授权 | 未砍既有生产批准/CAS字段；此差异保留，不能用原型演示发布替代真实授权 |
