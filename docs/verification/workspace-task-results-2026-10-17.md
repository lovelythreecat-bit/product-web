# 工作台任务化与详情重排验证

日期：2026-10-17。范围：用户指定的工作台四项改造，多个 agent 分工实施并独立评审。V2 暖色、Element Plus 和桌面紧凑密度继续有效。

## 实现

- 左侧真实按任务列出商品名称、任务编号、状态、时间；同一会话的任务分别选择，手机使用同一任务集合的选择器。新建任务保留独立草稿。
- URL 的 `?task=` 精确定位任务；中间仅展示所选任务的全部作品及作品中的全部条目。新受理任务和失败重试的新任务自动选中，普通刷新不改变选择。
- 删除聊天输入气泡及中间输入/参数摘要。任务状态、产物、预览/复制/下载/重新生成和费用结算继续保留；多份产物有编号与分隔，图片按完整比例排列。
- 后台重连保持已显示产物，删除核对原任务的提示；首次读取使用骨架，任务自身执行与结算状态仍显示。
- 任务详情沿用只读抽屉，重新分组为概览、生成输入、商品资料、参考素材、生成设置；完整输入默认可见，删除适用政策版本及原始政策 JSON。
- 保留收费确认、不可变输入快照、失败重试/积分释放、视频方案与补资料流程。未修改后端接口或计费政策。

## 验证

- 独立评审修复后，前端整合单测最终为 33 个文件、207 项通过，其中任务列表 8 项通过。
- Vue / TypeScript 检查及 Vite 生产构建通过。
- 桌面 1440×1000、手机 390×844，共 6 项浏览器回归通过，覆盖多份文案、同会话任务切换、输入仅详情显示、后台恢复不闪空、不显示核对提示、Escape 关闭及焦点恢复、新建独立任务、重进恢复、失败重试与释放积分。
- 追加图片场景在两种视口通过：三张图片均可加载，使用 contain 保留完整比例，页面没有横向溢出。
- Impeccable 对 5 个改动组件的机械检测均无发现。
- 独立评审发现的历史末页任务详情失败后重试无法找回的问题已修复：重试会补读全部已加载历史中缺失的详情，保留当前分页游标。回归用例先验证失败，再验证修复通过。身份切换则同步清空任务缓存并丢弃旧响应。
- 浏览器使用确定性 HTTP 夹具，图片复用已有首页示例资产。这些截图用于界面验证，不代表真实 Agent 新生成或生产验收。
