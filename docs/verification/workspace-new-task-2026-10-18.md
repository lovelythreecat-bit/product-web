# 工作台新建任务失败修复

日期：2026-10-18。范围：本机创作工作台新建草稿及相关后台账户锁争用。

## 原因与修复

- 浏览器点击「新建任务」已触发 `POST /api/v1/conversations`，但多次约 3 秒后返回 500。补充的安全错误日志确认是 `OperationalError`，MySQL 驱动错误码 2013。
- 只读查询 MySQL 活动语句、锁等待及持锁事务语句历史，定位到 `CallbackService.import_observations`：它在持有账户及任务锁时，逐条重新校验所有历史轮询记录，包括大量完全相同的记录，阻塞认证阶段的账户锁查询。
- 每次导入事务内按完整 observation payload 摘要去重，仅在原核验／持久化返回 ACCEPTED 或 DUPLICATE 后记录摘要。不同身份、结果及失败／冲突记录继续按原流程处理；不跨事务缓存，不删除历史，不改变收费或任务身份。
- 新建按钮等待时显示「创建中…」并禁用；创建失败提示紧跟按钮，独立于历史加载错误，后台刷新任务列表不再清除此提示。
- API 未预料错误仅记录响应 trace ID、异常类及数字驱动错误码，不输出异常正文、SQL 参数或凭据。
