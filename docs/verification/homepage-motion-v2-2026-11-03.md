# 首页动态 V2 实施

用户在本聊天确认“按这一版 把首页实现一下吧”，实施来源为 `docs/design/homepage-motion-concept-2026-11-02/` 的 V2，不是其他聊天仍待评审的首页稿。

## 结果与边界

- `HomeView.vue` 实现完整首页：分层大标题、三品类轮播舞台、玲玲邀请卡、滚动创作过程、图像／视频介绍、玲玲四步骤、双工作台、多店示意与结束行动。
- 保留原型所选营销原句。创作示例、动态分镜示意仍标注；未搬入原型评审工具、设计说明弹窗或策略文档全文。
- 注册、登录与工作台使用现有路由；已登录工作台沿用新标签打开。AI 客服入口保留。品牌名称继续由后台配置，未强制更改默认“映作”。
- 使用共享 ThemeToggle 和现有主题存储；浅色创作演示为浅底白面板，深色为墨蓝面板。
- `useHomepageMotion.ts` 管理轮播、滚动、离屏／后台暂停、系统减少动态效果和资源清理；离开首页取消 rAF、interval、监听器和观察器。无新增运行时依赖。
- 样式限定在 `.site-home` 内，动画名称带 `home-` 前缀。玲玲指定原图通过模块导入打包；商品 atlas 沿用现有构建发布入口。
- 真实案例继续仅从授权公开接口读取，接口错误可重试且不阻塞静态首页。
- 本次不实现真实数字人问答、视频生成或多店发布，不改变任务、费用和非首页业务流程；未部署。

## 验证

- Vue TypeScript 检查通过；Vite 生产构建通过。构建仍提示既有 UsageView 大于 500 kB 的包体积建议，不阻断构建。
- `site-content.spec.ts` 与 `brand-theme.spec.ts` 合计 16 项通过，覆盖首页内容、真实案例隔离／重试、轮播键盘控制、场景 inert 状态、玲玲提示、双工作台、暂停、减少动效、卸载清理、游客／会员入口及主题品牌行为。
- Windows 沙箱临时目录重命名导致初次 Vitest 启动失败；正常本地权限下测试通过。
- ego 浏览器：1440×1000 桌面、390×844 手机及 320px 窄屏无整页横向溢出。浅／深色首页与演示区已截图核查。手机取消长距离固定演示，保留点选。
