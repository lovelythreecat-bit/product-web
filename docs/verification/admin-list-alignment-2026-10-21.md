# 管理后台列表对齐修复

本次仅修复列表布局，不改变字段、操作入口或业务流程。

## 原因与修改

后台迁移至 Element Plus 后，旧 `.admin-table th/td` 仍使用 `vertical-align:top`，普通正文与具有内部留白的操作按钮因此不在同一水平线上。部分页面还单独覆盖单元格 padding，导致页面间表格间距不一致。

在 `frontend/src/features/admin/admin.css` 统一单元格垂直居中，Element Plus 单元格上下留白 10px、内容横向留白 12px，并补齐操作按钮组的 flex 布局与居中规则。保留数值列右对齐、现有按钮尺寸和表格内部滚动。
