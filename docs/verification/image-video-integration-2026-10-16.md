## 使用与剩余边界

1. 已有本机 18000 API 检查时仍是旧进程（没有新媒体路由），需按既有启动方式重启 API/Worker 才加载新代码；本次没有终止用户已有进程。临时验证进程不替代正式启动。
2. 在后台分别填写真实服务地址和服务访问 Key；视频管理 Token 可以分开保存。供应商 Key 通过模型配置写入上游。没有读取或填入用户的现有上游秘密，也没有默认创建真实供应商模型。
3. 图片建立服务、模型、Agent 方案后选择默认方案和实际生图别名。视频配置实际 planner/video 等角色绑定。真实生成仍须既有协议、输入、价格、异常和容量政策满足，不自动配置或打开门槛。
4. 商品长图的 HTTP 结果缺最终审核证明，目前禁止报价/提交；详情三图需要 D-04。部分交付和人工接受仍不被擅自当作收费成功。
5. 上游没有提交时 expected_config_version，图片提交及视频创建/确认各取上游当时快照。web 固定连接与配置引用，未声称消除上游配置提交窗口。
6. 图片未知受理且本地没有原 task ID 时，无可靠外部键查询/保留作用域证据，保持待核查，不自动重提。文件源/保存异常继续查原成果。

真实 Agent HTTP 联调、供应商生成、471 项跳过场景、生产迁移与公开上线未验证。本机连接表迁移和测试通过不代表生产验收。
