# 工作台侧栏滚动修复

日期：2026-10-15。依据：用户本次明确要求固定侧栏顶部入口、底部积分，仅最近会话过多时滚动。

## 实现

- 桌面工作台使用视口高度容器，顶栏自然占高，主内容独立滚动。
- 左侧顶部保留新建会话、我的作品，底部积分与充值始终可见。
- 最近会话占据中间剩余空间，超出时独立滚动；更多会话及读取错误随列表滚动。
- 规则仅用于桌面工作台；手机端保留历史选择器和原有页面滚动，其他页面不应用工作台高度限制。

## 实际验证

在正在运行的本地页面使用 Chrome DevTools 检查，未创建或修改服务端会话。
