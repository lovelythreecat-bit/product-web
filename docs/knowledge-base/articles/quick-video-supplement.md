# 补充视频所需资料

> 草稿，仅依据当前本地代码或设计资料；未经人工审核，不进入正式知识库，也不代表生产已上线。

## 用户可能怎么问
- 视频提示需要补资料怎么办？
- 补资料会新扣一次吗？

## 简洁回答
出现“需要补充以下资料后继续规划”时，按本任务问题点“补充资料”，填写真实信息后点“提交补充资料”。在原任务内继续规划，不新建收费任务。

## 前置条件
当前视频处于等待补充资料阶段；补充文字不能为空，最多 10000 字。

## 常见异常及处理
结果不明时用“核对并重试原操作”，不要重新创建视频。无法保存操作记录时，检查浏览器是否允许保存会话数据，不要清空待核对的原操作。

## 何时需要人工帮助
不知道真实商品信息时请商品负责人确认，客服不能代编成分、规格、功效或承诺。
