# 电商 AI 创作平台 · 首版交互原型说明

日期：2026-10-09；交互整理更新：2026-10-11。范围：设计交付与开发准备参考，不含业务实现。

唯一需求依据：[首版需求终稿](../电商AI创作平台-首版需求终稿-2026-10-09.md)。已确认产品决策、AC 验收要求和 D 启用门槛以该文件为准。这个原型不构成软件验收证据。

## 打开与演示

打开同目录 [index.html](index.html)，无需安装依赖、登录真实账户或联网。HTML、CSS、JS 和人工样例均在本目录；也可在主任务启动的本地预览 `http://127.0.0.1:8777/` 查看。所有账户、积分、规格、价格、任务、图片和视频均有演示标识。

导航使用 hash：`#home`、`#login`、`#register`、`#workspace`、`#works`、`#account`、`#recharge`、`#admin`。后台使用页内模块导航。浏览器返回可切换页面。

建议走查：创作工作台 → 编辑商品资料（抽屉）→ 保存 / 取消 → 切换 Agent → 展开生成设置 → AI 帮我完善（原位建议）→ 编辑 / 采用 / 撤回 → 确认费用并生成（确认弹窗）→ 原型演示区切换状态 → 任务详情（抽屉）→ 展开输入快照 → 作品预览（弹窗）→ 更多 → 删除确认。个人中心的编辑资料、积分流水详情与后台的新增用户、配置、发放积分、编辑产品介绍均为可点击的后续状态。

## 本轮交互整理

页面默认只保留内容摘要、当前状态、费用及常用按钮。商品和个人资料不再默认铺开完整表单；后台赠送配置、发放积分和官网介绍同样点击后打开。版本、输入快照、规则和生产门槛放进对应详情或折叠说明；收费承诺和当前异常仍在操作时可见。

前后台共用一套弹窗 / 抽屉：编辑使用保存 / 取消，只读使用关闭；删除使用明确对象和红色确认。取消、关闭或 Escape 不保存编辑；保存后更新摘要 / 列表；长表单固定底部操作区。手机采用全屏抽屉。任务详情、作品预览、资料编辑这些按钮已有实际点击后的界面，不以外部文字清单代替交互。

同时修复删除作品后历史任务的缺失结果提示，以及跨页面查看来源任务 / 重新生成时的滚动定位。

## 交互契约

Agent 由用户选择，参数区域按所选模拟能力矩阵显示。文本为通用文案；图片示例包含用途、比例、尺寸、张数和风格；视频包含时长、横竖屏、分辨率、配音、字幕与音乐。模拟项不代表 D-01～D-03 已完成。多结果、详情页形态与部分交付政策未确认时禁用相应规格。

生成前展示费用、规格和价格版本，并再次确认。旧报价失效先返回新报价说明，不创建任务或冻结积分；接受新报价后仍需再次确认。报价样例：文案 8、图片 20、视频 60 积分；均为演示值，不是生产价格。注册 200 积分也仅为演示值。

任务保存在本地对象集合，每卡按 task_id 读取该次实际资料、指令、素材标识/版本、全部参数、Agent 接入版本和 Quote，不再读取当前编辑器或固定杯子样例。受理时深复制并冻结快照；切 Agent、编辑、导航和新增任务只影响草稿。当前规格/报价接受 demo-p2 后，编辑器、确认框和新任务均为 p2，历史 p1 不变。

会话集合以 conversation_id 分隔草稿与任务。桌面侧栏和手机历史选择器均能切回至少两个会话；新建会话为空，原在途任务及全账户冻结保留。各 Agent 参数保存在各自草稿中，辅助预览编辑、采用、取消、撤回和页面切换均保留选择。撤回以 null 区分无备份和合法空原文，可恢复到空指令。

成功作品以完整结果保存为前提。临时文案片段不能被复制为正式作品或成为消费依据。未知受理状态维持冻结，禁止从该异常任务直接盲目重新生成；保存失败只恢复原结果下载与入库。关闭/刷新不会被展示为取消或失败。

“原型演示区”是明确标识、折叠的评审工具，可选择本会话任务，再切换其执行中、待核查、保存恢复、成功或确定失败。文案 8、图片 20、视频 60 各按受理时固定费用从可用转冻结，成功转消费，确定失败返可用；每次账户变更写同一本地流水，记录前后可用/冻结/消费、金额、任务和原因。终态不逆转，重复成功/失败不会再次结算。临时片段仅文案可用，异常和片段无正式作品。

“重置演示”和“积分不足”明确加载另一完整 fixture，原子替换任务/会话/作品/账户/流水；低余额场景以“演示入账撤销”行说明变动，非产品功能或真实账本操作。后台诊断、用户及用量是独立标识的 A-T / admin-fixture 样例，不代表个人账户，后台模拟发放/配置不改个人余额。

完整成功向本地作品集合幂等新增一件，作品可看到来源 task_id/conversation_id，预览、复制或播放下载使用该关联对象。作品“重新生成”先带回原输入为当前会话可编辑草稿，显示原任务来源，随后走统一资料/素材/余额/新报价校验和确认。原素材可用性可由评审区模拟为缺失；不受理或冻结，重新选择文件后可确认新报价创建新任务，旧成果保留。图片/视频仍引用同目录固定人工样例，不宣称生成了新商品照片或视频。

作品删除仅移出本地演示列表，确认框说明 D-09 门槛；不执行物理清理。真实文件、历史引用、恢复、停用与容量政策不得据此推定。辅助配额方案、重置规则和异常处置期限同样保持待确认。

后台默认不展示私有素材、指令或结果正文，授权申请只记录演示意图。真实访问必须校验独立权限范围，并审计人、对象、时间、原因。普通配置与诊断只展示脱敏状态，不录入真实秘密。未经授权的人工案例不能发布为真实作品。

## 样例来源与真实性

`assets/sample-image.png` 为浏览器渲染的人工文字版式样例，不是商品照片、真实 Agent 成果或真实官网案例。`assets/sample-video.webm` 为本地 Canvas 与 MediaRecorder 制作的约 2 秒演示短片，用于播放与下载路径验证，画面内有人工演示标识，不代表 5 秒视频规格的完整交付。文案由人工模板整理，只复述提交资料与指令；基线杯子事实仅有容量、杯盖和使用场景，不代表真实 Agent 输出。

没有调用 AI 服务、支付渠道、业务数据库、外部素材下载或真实用户数据。离线文件模式受浏览器剪贴板策略影响时，会展示可手动复制的文本框；文件预览和下载仍使用本地资源。

## 验证与未验证边界

本轮验证（2026-10-11）：[浏览器交互检查脚本](interaction-check.js) 在桌面 1440×1000 和手机 390×844 各通过 38 项；[结果与源码摘要](interaction-check-results.json) 保留具体断言。覆盖默认内容收起、抽屉保存 / 取消与焦点恢复、辅助采用 / 撤回、收费确认与固定快照、异常冻结、唯一结算、预览与删除、个人资料、流水详情和后台用户 / 积分 / 配置 / 官网介绍。桌面与手机的 8 个页面无整页水平溢出，手机另核对全部 8 个后台模块；浏览器错误 / 警告均为 0，5 份 JS 语法检查退出码为 0，机械界面扫描结果为空。手机抽屉另核对底部操作区始终可见。最终视觉修正统一抽屉表单双列对齐。

历史 P1 / F1 的原型验证和独立评审记录保留为制作历史，不作为本轮界面或独立评审通过的依据。

原型不验证：真实注册安全、账户隔离、文件鉴权、并发任务受理/数据库事务/数据库账本守恒、后台权限执行、SSE与Worker恢复、回调鉴权、存储配额/SSRF、真实 Agent/支付、全部读屏及跨浏览器兼容。本地重复操作防护只证明演示交互自洽，不是服务端幂等证明。本地模型仅在当前页面生命周期保留；刷新/重新打开会重置完整演示场景，真实持久化恢复须按计划实现。文件选择仅保留名称/本地演示标识，不实际上传或验证二进制。生产输入要求、异常期限、删除、账号停用和辅助政策继续按终稿 D 门槛。截图不能代替服务端证据。

独立评审与修复由主任务继续协调；本说明仅记录设计作者已执行的验证，不自行宣称独立评审通过。
