# 独立评审问题修复记录

日期：2026-10-11。范围：`docs/prototype/` 本地设计原型。依据：本项目设计基准、首版需求终稿与主评审确认的 A-01、A-02、A-03、B-2、B-4，以及独立最终复核发现的 R-06；保留现有浅色视觉、共享抽屉 / 弹窗和未决政策门槛。

| 问题 | 根因与修复 | 本次验证 |
| --- | --- | --- |
| A-01 P1 手机任务区挤压 | 无条件显式网格位置覆盖原单列断点。增加 ≤850px 的子项位置覆盖：准备表单全宽第一行，任务全宽第二行；851px 及桌面保留左右两列。 | 浏览器实际几何：390px 下两区均 362px；850px 下均 810px，任务在表单之后；1440px 与 851px 原两列位置保持。 |
| A-02 P2 整体重绘丢失焦点 | 重绘移除了触发元素，没有目标焦点。辅助展开聚焦可编辑建议；桌面会话恢复对应按钮，手机会话恢复选择器，后台模块恢复当前按钮，新建会话进入创作指令。 | 真实 Enter、Tab、输入验证辅助可编辑；会话、后台和新建连续操作焦点正确。 |
| A-03 P2 表格溢出无提示 | 表格只提供 CSS 横滚。共享绑定按实际 scrollWidth/clientWidth 显示提示，溢出时提供 tab stop、可访问名称和关联说明；ResizeObserver 在窗口 / 折叠区尺寸变化时更新。 | 桌面无溢出的个人 / 后台表格隐藏提示；手机两类表格有可见提示，键盘焦点和 ArrowRight 能实际滚动。 |
| B-2 P2 合法长商品名撑宽 | 摘要标题缺少长词断行。摘要标题增加 overflow-wrap:anywhere；会话标题和个人资料标题允许收缩、换行，字段上限不变。 | 实际保存 120 个连续 A，确认生成、提交后会话、任务快照详情和40字符昵称均不导致整页水平溢出：桌面 scrollWidth=1440，手机=390。 |
| B-4 P2 失败重试承诺不存在的成果 | 文案仅根据 sourceTaskId 判断重生成。改为核对来源任务状态、结算与正式成果：成功且已消费且成果存在时明示保留成果 / 再次收费；失败且已释放时明示沿用输入按当前报价创建新任务；已删除成果仅承诺保留历史任务与积分记录。 | 真正失败→释放→修改后重新提交；原累计消费88不变，新任务冻结8、可用112→104；有成果成功与已删除成果来源分别验证文案，未改变冻结 / 消费 / 释放逻辑。 |
| R-06 P2 异步关闭事件清空新弹窗 | 原生 close 事件排队，旧事件无条件清空共享 dialog 与提交动作，并恢复旧焦点；后台详情转编辑的一次性 close 监听也会被旧事件触发。统一 closeOverlay 同步清理当前实例；打开前收尾已关闭但事件未到达的实例；异步 close 在新实例仍打开时不做清理。Escape、确认、取消与后台详情→编辑共用同一生命周期，不再排队后台编辑回调。 | 同一 JavaScript 轮内关闭立即打开、两次取消后再开、收费取消后确认、旧 close 排队时后台详情→编辑，桌面 / 手机共8项修改前全失败、修改后全通过。取消后任务3/可用112/冻结0不变；确认后任务4/可用104/冻结8；当前弹窗可提交、焦点仍在取消，后台编辑只保存一次审计。 |
