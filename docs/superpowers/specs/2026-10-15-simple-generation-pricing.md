# 创作类型计价与参数配置

日期：2026-10-15。依据：用户要求“删除规格，同样删除规格与价格，增加参数配置页面……文本价格、图片价格、视频价格”。本条覆盖原需求及历史设计中的规格选择、规格管理和按规格配置价格流程。

后台入口改为「参数配置」(`/admin/parameters`)，使用既有暖色面板与编辑抽屉，只有文本价格、图片价格、视频价格三个业务字段。单位为积分 / 次；整数范围 0 至 9007199254740991；留空为未配置，0 为不收取积分。保存、取消、管理员权限、CSRF、冲突保护和修改审计沿用现有语义。旧后台规格/价格路由跳转新页面；旧公开规格与后台规格/价格 API 已移除。

`GET/PATCH /api/v1/admin/parameter-config` 按运行 mode 保存配置。GET 返回 `version` 和三个可空价格；PATCH 接受 `expected_version` 和三个价格。修改写入不可变新版本并在同事务推进 head 和记录审计，不覆盖历史。无通用设置表可复用，因此新增 `0026_generation_parameters`，初始化 mock/staging/production 空 head，不预填任何费用。

工作台取消生成规格与无剩余字段的生成设置区域。`POST /api/v1/quotes` 使用 `agent_id` + `input`，新创作 `input.parameters={}`；按 Agent 的 copy/image/video 分别读取文本/图片/视频价格。未配置不报价、不受理。AI 辅助请求只绑定 Agent 及版本，不依赖规格。历史作品再次创作保留商品、素材、指令，使用当前计价，移除旧规格参数；已有待核对原提交保留完整请求和幂等键。

为兼容历史任务、执行、报价快照与账本，保留 Quote 的既有内部字段和历史表，不删除历史事实。新任务采用服务端固定单结果 envelope，内部 `spec_id=agent_id`、`spec_version=agent_version`，不是业务配置或可选规格。报价绑定整份价格版本、Agent 版本、输入 digest；受理同事务共享锁定价格 head。改价后新意图必须重新确认，客户端不得自动重新提交。已受理原意图在重新校价之前重放，保持原价且不再次冻结。旧报价尚未受理时新提交返回 QUOTE_STALE。

新单结果任务的完成规则由已实现协议维护，严格核对原任务与内部完整 envelope、协议和 D-01 绑定、空参数、单个 original-1、MIME、locator 和完整交付；无需管理员维护旧 result_specs。历史无新计价标记任务继续使用原快照与原结果政策。存储下载、内容验证、容量占用和结算检查保持。

文本继续使用数据库服务连接及管理员指定默认模型；未改图片/视频真实接入状态，未新增上游能力。报价不代表当前能力已开放。生成开放、D-01/D-03/D-05/D-08/D-09/D-10、并发和持久化容量门槛继续生效。

部署时先应用 0026 迁移，再由管理员填写所需价格。受信任 `APP_GENERATION_CAPACITY_ESTIMATES` 对新提交按 **Agent UUID** 配置，`spec_version` 必须等于该 Agent 的版本（内部文本为 `text-agent-v1`），同时精确匹配 D-10 版本及 estimation_ref；字节数须由已审查的输出上界给出。没有按旧规格、首个匹配项或 0 字节的容量回退。不擅自迁移历史费用或容量数值。
