# 独立 Agent 服务桥接准备

用户已说明 textAgent/imageAgent/videoAgent 尚未封装 HTTP，并选择先准备独立服务桥接。本设计沿用已确认平台计划的 AgentAdapter 边界与代码优先、单开发者、限定评审方式；服务实现不确认生产协议或调用真实模型。已有三项目只读使用，不改源项目、秘密或其运行数据。

## 目的与选择

把已有 Python 库入口包装为可独立启动的 HTTP 服务，先具备持久提交标识、查单和完整成果读取能力。沿用 Python/FastAPI、MySQL 与持久硬盘；文案/图片的库调用不能直接视为网络幂等。独立服务的持久提交记录隔离平台与库调用，保持现有 AgentAdapter 接口，不让前端直接调用 Agent。

不将库同步方法直接放在 HTTP 请求线程里重跑。提交先保存不变输入、摘要和稳定 job ID；工作进程领取后在数据库事务外调用库。调用开始后的崩溃、超时或不明异常进入待核查，不默认重新调用。已接受的同意图重放只返回原 job，同键异参冲突。查询缺失不出具“确定未受理”或安全重试证明。

## 接口与持久语义

候选协议为独立 bridge-v1，保持 draft。统一健康/能力、submit、按 external_submission_id 查询、按 job ID 查询、完整结果/文件读取，全部业务入口使用独立服务凭据并验证调用范围。请求关联平台 task/user/Agent/protocol/source版本与输入摘要，同意图唯一键至少隔离 Agent、调用账户和 external_submission_id；不同调用账户不得读或重放他人的记录。

MySQL 是桥接提交与调用状态的事实源，原输入不可变；文件完整落盘并校验摘要后才能发布完整 manifest。服务重启仍查到同一 job，不因 HTTP 断线或查单请求触发新生成。调用前的待办可领取，调用已开始但完成记录缺失不自动再领取生成。服务没有可靠原结果恢复能力时明确 UNKNOWN/待核查；不把 partial、普通404、超时或保存失败当作成功、确定失败或释放依据。

## 三类库接线

- 文案：CopywritingAgent.agenerate(CopyRequest) 返回完整 CopyResult；空文本拒绝完整发布，usage缺失为不可获得。不伪装上游文本流。模型适配器通过明确的服务器配置工厂注入，不能由请求指定模块或凭据。
- 图片：CreationRequestDTO经受控素材绑定转换，create_images与ResultBundle保留资产状态、审核与完整性。blob存在不等于批准/成功，部分结果保留待核查。resume_images仅针对固定原run/checkpoint的显式恢复能力，不默认重跑create_images。
- 视频：VideoAgent(home=桥接专属持久目录)保存自身任务与素材，不能使用或修改兄弟项目既有home。create_task绑定原幂等标识，get_task/list_artifacts读取固定原任务；confirm是独立步骤，桥接明确呈现需要确认的状态与固定方案版本，不能擅自确认或重新生成。其内部SQLite是上游库执行细节，不替代平台/桥接MySQL事实。

真实驱动和配置接线可编写但默认关闭；首轮用注入替身验证网络与持久语义，不安装/启动原库、不读取其秘密、不真实生成。平台真实字段映射/D01-D04、视频确认流程、恢复保证仍待实际联调与权威确认；候选适配器不得在现有生产registry中默认启用。

## 数据与运行边界

素材与结果仅接受有范围绑定、大小/MIME/摘要校验的受控字节或内部ID，不信任请求指定服务器路径或任意下载URL。持久根与release分离，产物读取只经授权HTTP接口，无私有目录静态别名。日志不记录原正文、素材字节、供应商原始错误或凭据。

候选部署按文案、图片、视频独立进程/配置/凭据启动，可共用明确配置的MySQL服务但独立命名空间。持久表不对平台私有模型创建跨服务外键。默认loopback/内部部署，未提供凭据/持久连接或必要确认配置时不可接受真实调用，不自动启用生产。

## 代码交付与检查

运行工具T22a完成后逐步实现桥接代码与候选协议、启动说明及受控驱动接线，一位开发者。只做同键重放/异参及跨范围拒绝、重启后查原/调用开始不重跑、完整/部分/保存失败分支与受控文件读取等最小定向检查和适用静态，一次限定diff评审。三真实库/模型/生产协议未验证，不能将替身PASS记作真实联调；全场景、故障矩阵和公开部署后移。
