# 快速生成实施计划

依据：用户要求按 `docs/design/quick-generation-2026-10-18/` V1.1 原型实施。原型作为本轮已指定设计，不重新设计字段或要求重复批准。沿用当前未提交的工作台、Agent、收费和任务恢复能力，在当前工作区增量实现。

1. 服务端新增账户所属的快速生成流程表及迁移；保存草稿、步骤、人工确认版本、批次和不可变收费请求，采用版本号防止并发覆盖。
2. 提供创建、列表、读取、保存、报价、确认提交、阶段确认接口。图片组合在同一事务中受理，任一受理失败回滚整个新批次；执行和结算仍逐任务独立。重复确认使用服务端固定幂等键。失败重试与释放继续调用原任务能力，并追踪重试后继。
3. 确认后的可编辑文案作为图片和视频指令的一部分，历史文案与任务快照不变。上游资料变化使下游确认失效，保留已有成果和费用；不自动继续收费。
4. 工作台新增入口和流程历史；四步页面复用商品动态字段、Element Plus 控件、作品预览、任务详情与视频方案确认。增加保存退出、返回、继续、完整结果汇总。
5. 先写关键状态/权限/幂等测试，再实现；验证类型、构建、后端与前端相关测试，并在桌面和手机浏览器核对原型和截图。只对实际证据报告通过；真实 Agent 生成与生产发布单独说明。

实施记录：以上步骤已完成。新增迁移已应用至本地 mock 数据库，API 已重载且就绪；真实数据库的保存/重读/权限/并发版本/报价取消在外层回滚事务验证，未遗留测试账户。定向后端 43 项、前端 26 项及两种视口完整流程通过。独立代码复核发现的恢复、轮询与导航问题已修正；全量回归中四项无关既有测试失败及真实 Agent 未验边界记录于 `docs/verification/quick-generation-2026-10-18.md`。
