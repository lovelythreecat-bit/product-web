## 已确认范围

创作工作台内的快速生成：整体内容区、四步导航、商品资料、文案、图片、视频、完成汇总、相关弹窗/抽屉，以及加载、空白、失败和历史只读状态；覆盖桌面和手机。公共顶栏与任务侧栏仅作上下文展示，不纳入重设计；普通任务及其他页面不改。

## 本稿视觉提案

- 沿用 V2 奶油米色、陶土橙及中文系统无衬线字体。使用现有色值，主要动作和当前步骤使用陶土橙，其余操作降低强调。
- 统一四步导航与当前内容标题。桌面保留顶部步骤与底部操作，中间内容独立滚动；手机自然单列滚动。
- 商品确认：左侧参考图、右侧分组表单；基本信息、规格参数、卖点与使用场景保持当前分组。10 类商品动态字段映射自当前代码，长文本完整保留。
- 文案：暖灰画布上的白色编辑区，桌面两列、宽屏三列、手机单列；标题、编辑状态及复制/重生成操作统一层级。
- 图片：主图、三张详情图、完整商品长图分别展示，统一状态、详情与下载位置；预览保持完整作品。
- 视频：首帧缩略图选择，方案以只读抽屉展示，编辑与补资料保留抽屉、费用与执行确认保留居中弹窗。
- 完成：文案、图片、视频分区汇总，只读查看保留成果和详情，不展示重新生成等修改动作。

## 当前实现核对与依据

读取 `docs/product-design.md`、整改手册、需求终稿、V2 视觉规范、快速生成 V1.1 原型，以及当前 `QuickGenerationView.vue`、`QuickProductEditor.vue`、`QuickCopyRequirements.vue`、`useQuickGeneration.ts`、`productTypes.ts`、`TextChoices.vue`、`VideoTaskPanel.vue`、任务详情组件。

当前代码较早期原型已有变化：商品资料为页内表单；文案类型默认七项且可自定义，要求弹窗当前只展示类型、平台、语气；视频首帧支持上传素材及本次已确认生成图；有方案编辑、重新规划和免费重生成剩余次数。预览据当前代码呈现，不把早期原型覆盖回去；本稿不批准或改变任何业务政策。

ui-ux-pro-max 查询「form labels grouping feedback」命中明确标签、反馈、可访问名称等规则，应用于预览。Vue 栈首次检索无结果，改为「forms」后命中表单库和 v-model 建议；本轮只做静态视觉稿，不据此新增依赖或更换当前表单方案。

## 示例边界

商品、文案、任务编号、账户、时间、张数、报价和视频参数均为评审示例。摄影复用 `../quick-generation-2026-10-18/assets/commerce-categories-v3.png` 的耳机区域，图标使用线性 SVG，品牌复用项目原资产。详情图与长图用示例素材排版，视频仅有封面占位，不是真实生成成果。

静态稿不模拟完整业务：不同生成组合仍跳转到统一示例成果；下载及视频播放提示边界；资料仅在当前预览内编辑，上传只读本地文件；不会保存真实商品、发起收费、调用 Agent 或改变任务。实施时复用现有 Vue / Element Plus 组件、校验、字段与服务端状态，不把此稿脚本移入生产。
