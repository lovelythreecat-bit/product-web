## 本轮视觉

沿用飞马蓝色体系：冷白背景、深蓝标题、蓝色操作与自然商品摄影。16 区各自有空间，维持已确认的模块顺序、信息层级和文字范围。原型中的占位图替换为商品、成果和场景画面；设计注释不进入营销正文。

第三部分采用两列三行、每组左图右文：多品类成果、原图与成图、主图组合、创作分镜、玲玲、竖屏带货视频。玲玲以用户提供的 `output/figma-assets-20261102/01-character-front.png` 作为形象参考；正式实现优先直接使用该原资产。生图中的人物是参考图引导的重绘，不能当作原资产像素不变的证明。

全部 49 个原文区块继续按原型对应到 16 区，图片提示词附逐字原文，图库另有可复制的完整原文。图片文字以实际目视核对结果为准，不能以提示词和文档完整代替位图无误证明。正式实现从原文数据渲染 HTML，不把整张设计图当页面，不对原文摘要或删减。

## 后续动画方向

以下为高保真对应的实施建议，本轮为静态图片，未实现动画：

| 模块 | 动画位置 | 阅读与操作要求 |
| --- | --- | --- |
| m01 首屏 | 商品与成果以 60–100ms 间隔轻微上移显现；桌面商品区小幅指针景深 | 文案不打字、不等待动画才可读；品牌与主按钮稳定 |
| m02 品牌定位 | 定位与主张轻淡入一次 | 长段落不逐字播放 |
| m03 六组 Slogan | 六组图文按阅读顺序显现，图片悬停轻微放大 | 不轮播、不自动换句；触屏直接展示 |
| m04 产品介绍 | 玲玲与正文分层淡入 | 保持原角色；不模拟实时客服状态 |
| m05 图片 | 三类成果先后显现 | 原图与成果不互相遮住；始终可查看 |
| m06 视频 | 点击后播放示例，封面保持稳定 | 不自动播声音；控件可键盘操作 |
| m07 工作台与玲玲 | 工作台预览、角色依次出现 | 不伪造在线、生成完成或用户对话 |
| m08 分发 | 关系线一次描绘，突出来源与去向 | 不显示虚构的发布成功反馈 |
| m09a–m09b 场景 | 分镜或成果依次入场 | 保持完整场景文字，手机不做大幅视差 |
| m10–m11 概览与收尾 | 功能按组轻显现；按钮有简洁悬停反馈 | 占位数字静态保留，不做增长计数暗示真实数据 |
| m12a–m13 长文与页尾 | 最小或无动画 | 全文直接可读，无内部滚动、跑马灯或自动折叠 |

共通：仅使用 transform/opacity 等适度效果；离屏暂停，手机减少效果，`prefers-reduced-motion` 下完整静态展示。生产阶段沿用现有 Vue 技术栈，不因外部动效参考引入 React。动画时长与性能需在具体实现时实测。

## 制作与范围

三位 Agent 分别负责品牌、功能场景、后段内容，主调度负责首屏、统一参考、独立核对与图库。使用内置 imagegen，每模块独立生成，保存提示词、原文 sidecar、分组 manifest 与检查备注；未使用 CLI 替代，也未声称内置工具返回了可验证的具体模型版本。

角色引用和商品图属于设计参考；示例标记不等于真实用户案例。源文中的功能承诺与统计占位按用户要求保留，不能由设计图推断功能已实现或数据真实。

没有修改生产首页、业务代码或部署。确认具体高保真模块后，才进入该模块的前端和动画实施。深色首屏是主题对照，不代表其余深色模块或移动端高保真已逐张完成。
