## 本次效果

Three.js 实时绘制带完整材质贴图的鞋类商品模型、环境反射和悬浮构图；滚动带动镜头、成果的空间展开和竖屏分镜重组。鼠标改变观察角度，分镜可重播，专业／小白模式改变相应展示。玲玲是指定原图的透明平面，未声称是三维角色模型。视频区为三维分镜示意，不冒充实际生成视频。

动效默认播放，底栏可暂停；手机保留场景，系统减少动态效果时静止展示，后台标签停止渲染。WebGL 不可用时静态回退。创作 CTA 仅展示预览说明，不调用业务或消耗积分。
