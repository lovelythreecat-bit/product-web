## 密度与公共样式建议

- 统一由主 Agent 控制每模块约 1440×800—1100，允许长内容自然增高，不用固定高度裁剪。
- m10 可约 1000—1100px 高：Hero 构图占上半段，四项功能放下半段，每项文字只保留自己的清楚层级，不再增加卡内小图。
- m12a、m12c 正文列以 480—576px 为宜，18px 正文、1.9—2.1 行高，原文换行保留；模块间留白大于卡内留白。
- m12b 原文较短，使用主文案层级和较大留白，勿额外加入多张卡片凑满页面。
- m13 每条 CTA 样式允许换行，不用省略号，页尾建议 18px 及清楚对比，不能因低层级缩成难读小字。
- 所有 image-slot / film-slot 均为灰阶线框占位，无新增图片资源。本片段不使用玲玲参考图片，避免整页角色重复过多。

1. m10：章节题 → Hero 全文 → Hero 占位图 → 功能卡片区标题 → 四项功能按原 ID 顺序单列。
