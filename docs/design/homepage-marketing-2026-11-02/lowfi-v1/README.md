## 动效方向

模块上方灰色评审栏记录后续动效位置，不写入营销正文。本稿不演示成品动画：

- 首屏：商品与成果分层入场，可进一步探索轻微景深；原文始终可阅读。
- 图片与视频：成果依次显现、镜头节奏展示；视频不自动播放声音。
- 双工作台与玲玲：结构和角色依次出现，采用用户原角色，不制作伪实时对话状态。
- 多店分发：关系连线依次显现，不假造发布成功反馈。
- 长文：稳定排版，不用轮播、逐字播放或内层滚动代替全文。
- 手机、减少动态效果设置下完整静态展示，动画不改变内容范围。

参考沿用上轮实际查看过的 [Container Scroll Animation](https://ui.aceternity.com/components/container-scroll-animation) 与 [3D Card Effect](https://ui.aceternity.com/components/3d-card-effect)，只借鉴运动形式；未复制组件代码，未引入 React 或新依赖。最终动效仍待高保真阶段结合各区块决定。
