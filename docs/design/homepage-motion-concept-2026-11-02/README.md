## 页面与动效

| 区域 | 营销作用与选用原文 | 动态表现 |
| --- | --- | --- |
| 首屏 | “一站式电商内容工具，小白十分钟高效出片”；保留封面产品概述与“免费开始创作” | 左侧分层大标题、笔划描绘与数字人邀请卡；右侧三类商品环形轮换、轻微视差和动态分镜标识；次行动进入玲玲介绍 |

| 图像与视频 | “传统电商的爆款流水线”“抖店带货的流量引擎”及对应卖点段落 | 商品画廊鼠标轻微倾斜；视频区域为图片运镜和节奏线示意 |
| 玲玲 | “你不需要会设计，只需要会说话。”及数字人陪练文案 | 角色轻微浮动，四步骤点按切换陪练提示 |
| 双工作台 | “专业与小白，各得其法”及新手、专业文案 | 小白／专业切换对应表达，非实际工作台操作 |
| 多店发布 | “一键多店发布 · 素材即生产力”及对应段落 | 一套素材向多个店铺的路径示意；没有伪造发布成功状态 |

内容在 HTML 中可选中、可检索；未用整张图片承载页面。浅色／深色可切换。手机取消长距离固定舞台，改为点按切换；小白文案、专业文案仍可完整查看。动效可暂停，系统减少动态效果时停用自动动画，离屏或后台暂停画面动画。

## 参考与取舍

使用用户指定的 [ui-inspiration](C:/Users/呜啦啦/.codex/skills/ui-inspiration/SKILL.md)，通过 ego 浏览器访问并操作以下演示：

| 具体案例 | 实际观察 | 采用方式 |
| --- | --- | --- |
| [Container Scroll Animation](https://ui.aceternity.com/components/container-scroll-animation) | 向下滚动后，示例面板从 rotateX(20deg) 转为正面 | 作为主要参考，应用于素材展示舞台，保持飞马色系 |
| [Scroll Stack](https://reactbits.dev/components/scroll-stack) | 内部滚动时，前一幅画面缩小、压暗，后续画面叠入 | 借鉴成果逐步成形的层次；不把全部卖点做成堆叠卡片 |
| [Tilted Card](https://reactbits.dev/components/tilted-card) | 移动指针后画面绕 X/Y 轴倾斜并轻微放大 | 仅用于商品画廊，触屏不用此动作承载内容 |
| [Circular Gallery](https://reactbits.dev/components/circular-gallery) | V2 新查看：拖动画廊后，图片沿弧线横向移动、中心画面更突出 | 借鉴环形空间与前后层次，用 CSS/DOM 实现品类轮换；未复制其 WebGL 实现 |

只借鉴视觉与交互思路，没有复制第三方代码、模板、素材或提示词，因此未新增 React、动画库、WebGL 依赖。原型使用 CSS 与原生 JavaScript；正式实施时可适配现有 Vue 3，并复用站点组件。未声称第三方资源的商用许可已核对。
