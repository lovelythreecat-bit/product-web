## 事实与选择

受众是需要为商品准备文案、图片与视频素材的中文电商商家。主视口 1440×900，手机 390×844。用户选择可滚动网页稿并复用现有素材。本轮遵循 product-design.md 最新蓝色双主题与摄影 V3，覆盖整改手册历史暖色建议；保留完整飞马 Logo、玲玲原图与营销原句，不复制全文手册。

北极星：让商品与创作成果像一组值得停下来看看的广告作品，读完就知道从哪里开始。

独立概念生成给出“商品登场，成果展开 / 商品主角海报 / 一句想法，一幕成片”。选商品主角海报的通栏大字与摄影编排，接续同一手机的创作链。品牌方向已确认，本次探索局部构图，不引入新品牌。

首屏唯一主角为商品摄影展台；主动作“注册体验”，次动作“探索创作能力”使用文字链接。注册指向现有本地应用 /register；预览不伪造注册成功，不执行生成、不消费积分。

## 方向卡

- 骨架：通栏上下堆叠。顶栏72px；品牌说明24px；大标题90px；简述与主动作约100px；商品摄影三联展台约440px；页底品类与创作示例说明。中心手机大图、两侧美妆/音频为较小陪衬，无旋转卡片、粒子、轨道和统计指标。
- 字体：Microsoft YaHei UI / PingFang SC / sans-serif。首屏 clamp(40px,6.2vw,90px)，章节48px，正文16px，辅助14px。中文标题行高1.25。
- 色彩：飞马#1559d6、冷白#f3f6fb、正文#182843；暗色#0b1220、正文#eaf1ff、强调#79aaff。图片保持原色。选择态与边框沿用#e9f1ff/#dbe3ef。
- 主视觉：摄影V3手机、美妆、音频三联展台；同款手机原图、广告、细节与人物用于创作示例；鞋服放在宽幅画廊；玲玲使用指定原图。
- 参考：已查看本项目摄影V3实际首屏和手机原图，保留图片质感与蓝色身份，替换旋转卡片和环绕轨道。交互沿用本地页面的主题和锚点导航，注册不创造新流程。本轮是已确认品牌内构图提案，未使用外部标杆。
- 核心动作：注册体验→现有本地注册页；探索创作→创作段落；图片/文案/视频按钮→切换对应画面与说明；浅深切换→全页主题变化。
- 页面：摄影首屏→同款商品的三类创作→多品类错落画廊→玲玲陪练与双工作台介绍→使用流程→结束行动与页脚。
- 动效：“咔嗒，摄影选片归位”：按钮按下2%，作品切换250ms，首屏分层出场合计600ms；滚动时手机成果由单张展开为广告与细节双图，GSAP ScrollTrigger驱动，不绑架滚轮；章节按图像揭幕/标题上移分别出场。减少动态效果时内容直接到位，手机关闭固定长场景。
- 放弃：不做后台式功能卡片墙、无关机器人、装饰轨道、假指标和虚假客户背书。保留“创作示例”以明确资产性质。
- 技术成本：独立HTML/CSS/JS；本地复用图片；GSAP固定版本本地文件。正式Vue首页、接口和非首页流程均不在本轮范围。
