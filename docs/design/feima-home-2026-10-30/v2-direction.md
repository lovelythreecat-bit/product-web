## 用户新增授权

用户明确表示：首页允许大胆设计，可颠覆现有设计，包含文案、图片。因此本轮不受 V1 首页构图及既有商品摄影约束；保留电商 AI 文案、图片、视频创作的真实产品定位。此次自由仅限首页提案，不修改正式组件或全站设计基准。

## 方向

以“把商品，变成主角。”为核心的新首页：蓝色沉浸首屏、超大中文排版、全新多品类商品舞台，搭配有节奏的浅色内容区。以真实用途和可读的操作入口组织信息，避免用后台卡片或虚构数据撑页面。

使用 ui-ux-pro-max 作为层级与可读性参考；使用 imagegen 技能生成全新高保真概念视觉。用户生图模型偏好为 gpt-image-2.5；内置工具不提供模型选择参数，本次不主动切换模型。具体文字以设计说明登记为准，不将生成图中文字直接移入正式代码。

## 设计逻辑与系统范围

首屏是深蓝空间与商品舞台，橙色仅强调主要行动与商品细节；能力区回到浅色编辑式网格，场景区用深色与错位大图加强节奏，流程区简洁，结尾再次以蓝色大标题收束。主图和摄影摆脱旧方案的奶油色商品、铜色底座与统一圆角卡片。

本轮 ui-ux-pro-max 检索 `creative commerce editorial immersive --design-system --variance 8 --density 3` 命中 Hero + Features + CTA，以及 Brutalism。采用大字体、不对称构图、强对比与简洁结构；粗糙反设计风格、默认黑粉配色不适合本轮高质感商品创作定位，因此没有直接套用。所有新色彩与字体排布均为首页 V2 提案，不替换全站 DESIGN.md。

## 手机端计划

尚未交付 V2 手机高保真图；V1 手机图不代表 V2 设计已完成。

建议顺序：品牌与精简入口 → 主标题与行动 → 完整商品舞台 → 文案／图片／视频能力单列 → 品类场景 → 四步流程 → 底部行动。桌面的错位场景图在手机上改为依次展示，取消透视与重叠；商品主图裁切时确保鞋、瓶与耳机主体可识别。中文标题建议 40–48px，正文不低于 16px，主要操作保留 44px 以上触控范围。窄屏不复制桌面密集的细小注释。

## 素材与业务边界

- 所有商品、文案、图片及视频分镜为新生成的设计示例，不是真实客户成果。
- 视频仅展示分镜，不是已生成的可播放视频；不得把分镜装成真实视频。
- 不包含销量保证、客户数量、价格、生成速度或已上线能力承诺。
- 主按钮后续按登录态连接注册或工作台，能力选择和生成费用继续服从现有业务流程，不增加自动串联三种 Agent 或自动发布。
- 本次没有修改 frontend、后端、共享主题或生产配置，没有部署。
- 用户确认具体 V2 图后，再拆分独立素材、补响应式设计并开始正式首页实现；后续不得整图嵌入冒充页面。
