## 手机设计

顺序：精简导航 → 价值标题 → 注册行动 → 商品图 → 文案示例 → 视频分镜示意 → 三条能力 → 品类单列 → 两列四步流程 → 底部注册 → 页脚。三种成果展台在手机端堆叠，页内导航在窄屏收起，保留品牌、主题切换与注册。图片保持比例，通过 CSS 窗口裁切展示，未拉伸原图。手机长图为真实浏览器截图，并非把桌面图缩小。
