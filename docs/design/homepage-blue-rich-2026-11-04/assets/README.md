## 整合约束

1. 本板是图像素材，不替代 banner(1).html 的原文或结构。
2. 最终平面稿保留原 HTML 整体布局、模块顺序、各模块原文与网格数量。文案在图像之外排布，不让图片吞掉原段落。
3. 优先让实物摄影占图像面积，不要退回只有空卡片和线图标的处理。
4. 工作台、对话与时间线只是无字视觉示意，不构成功能承诺。
5. 素材板整体输出为约 4:3 横版，单格属于设计参考分辨率；最终平面稿可重新绘制或作为同款商品的参考，不能声称这些是生产级独立大图。
6. 视检未发现明显的文字乱写、logo、橙色 UI 或缺失格；第 7 格真实草莓红色为商品自然色，并非 UI 强调色。
