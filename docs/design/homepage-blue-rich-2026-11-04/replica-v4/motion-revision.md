# V4 固定导航与动效微调

日期：2026-11-04。用户确认后实施，仅影响 standalone/feima-home-v4，未接入或部署业务系统。

## 修改

- 首屏人物的原图边缘曾因 z-index 高于轮播框而露在卡片左下角；将人物层放在轮播框之后，保留人物主体与卡片内容。
- 将导航移到 hero 外、仍处于 page-content 内；固定在视口顶端，保留原首屏占位。顶部透明、滚动超过 12px 后平滑显示不透明蓝底。手机导航保留折叠菜单，锚点预留导航高度加 16px。
- 首屏标题、操作、人物、工作区依次入场，700ms、总延迟不超过 200ms；内容进入视野只运行一次，560ms、错开不超过 135ms。标题下划线短距离展开，图片轻微放大及按钮反馈配合交互。
- 轮播使用 240ms 退出与 460ms 进入的交叠过渡。离开的面板立即设为 inert / aria-hidden，过渡后 hidden。连续点击会取消旧动画，避免残留。保留 5000ms、点击重计时、键盘及暂停逻辑；改为单次定时器，不再为隐藏进度条逐帧写样式。
- 弹窗进入 320ms、遮罩 240ms。CSS 和 Web Animations 都尊重 prefers-reduced-motion；取消空间动效并保留可用的静态内容。默认 DOM 可见，不依赖入场动画才能读取。

- ego 浏览器 1440、1920、390px：页面 scrollWidth 等于视口，无破图、无捕获到的页面错误；首屏高度与前版一致。
- 导航滚动后 top=0；桌面高 82.97px、手机高 72px；行业板块顶部约 99px / 88px，不被遮挡。手机菜单点选后关闭。
- 首屏截图确认轮播框左下角露出已消除。滚动导航蓝底已改为全不透明，避免下方正文透出。
- 连续切换 1→2→0 后，仅 pane-0 可见且可交互；键盘 ArrowLeft 选择与焦点一致。
- 采样确认新面板 opacity 从 0 平滑到 1、过渡后仅一个面板可见。减少动态效果时无运行中的动画、轮播默认暂停。
- 自动轮播最终实测 5009.5ms。弹窗关闭后 page-content.inert=false，焦点恢复到免费试用按钮。
- 代码语法检查通过。没有在此局部任务中运行生产前后端测试。
