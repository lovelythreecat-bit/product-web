# V4 复刻：设计差异与 1024px 坐标标尺

分析角色：`/root/replica_difference_audit`。2026-11-04。

本报告实际查看了 `revision-v3/upper-v3.png`、`middle-v3.png`、`lower-v3.png` 及旧页面 `desktop-full-1440.png`，并读取旧 `standalone/feima-home-v3/index.html` 与 `styles.css`。仅分析，没有改页面或素材。

## 结论

旧版保留了文案和模块数量，但没有还原设计的视觉比例。核心差异是：内容区过窄、字体相对画布过小、横条过高、商品素材构图不一致、玲玲姿态不一致，以及复杂商品/电脑/分发插画被简单 CSS 拼贴代替。它不是可以通过调整几个色值修好的版本。

设计是三张 1024×1536 平面稿，按上/中/下顺序拼接后基准为 **1024×4608**。下述坐标为看图测读，通常 ±3–6px，不能伪称算法测量。构图框和文字的实际墨迹边界需在同尺寸网页截图中再校正。

旧截图实际 1430×7084，归一到1024宽约5073高，比稿长约465px/10%。**这只是宽屏截图等比缩放的观察，不是1024浏览器真实结果。** 主代理随后在 ego 实测1024宽旧页高度为 **6917px**，比设计4608px长 **2309px/50.1%**，说明旧响应式规则还额外改变了1024下的内容密度。旧 `.container` 最大1280，在1430画布边距75px，归一边距54px；稿主面板边距18–22px。仅这一项就使所有模块显得窄、松、细小。

## 总体尺寸规则

| 项目 | 稿件目标（1024px） | 旧实现差异 | 修复要求 |
|---|---|---|---|
| 主面板 | x18–22，宽980–989 | 1280封顶带来宽屏大边距 | 桌面先以1024基准忠实还原，视觉单位随桌面画布同比缩放；不要保留旧1280固定上限造成归一后变窄 |
| 主面板外间距 | 约10–12px | 18–24px且内部留白更大 | 用各段坐标表，勿全局随意拉开 |
| 主面板圆角 | 18–23px，细白/淡蓝双层边 | 近似单色边与平直渐变 | 保留轻微玻璃边、高光、淡蓝漫反射 |
| 七个标题 | 约32–35px，粗黑蓝，行高1.2 | 34px在1440图归一仅24px | 按1024坐标采用32–35px，居中 |
| 标题下划线 | 50–53×4px，距文字下缘13–18px | 62px且顶间距17，归一比例失真 | 统一同一个基准尺寸 |
| 正文 | 大多数14–16px，行高1.3–1.5 | 16px归一11.5px，行高1.7 | 不以过大行高抵消过小字号；按真实文字换行点调宽 |
| 卡片标题 | 19–24px，紧凑粗体 | 旧比例偏小且文本周围空白过多 | 逐区给尺寸，不用一个宽松排版体系覆盖全部 |
| 白色背景 | 冷白/浅蓝，局部暖反射来自照片 | 大面积统一平淡蓝 | 需要摄影与蓝白高光带来层次，非多加边框 |
| 图标 | 白色实心/线图形置蓝色渐变方块 | 多处换成裸蓝描边SVG | 对齐原稿方块尺寸、轮廓与填充；不新增橙色焦点圈 |
| 交互 | 首屏3卡及5秒提示 | 额外暂停文字占主提示横排 | 保留可访问暂停，但弱化为小图标或焦点可见控件，不扩大稿中提示区域 |

建议正文首先用微软雅黑/微软雅黑UI实测；设计稿汉字较粗，标题至少800，但字体不是简单把全站字重调大。准确营销文案仍以现有登记文本为准，不能照抄生图中的错字。

## 素材缺口（交素材角色）

1. 玲玲迎宾/伸手大半身透明素材，至少首屏和引导条使用；小白场景指向商品的半身姿态。现有站立全身同角色不等于同构图。
2. 首屏真实笔记本透视组件与右上杯/布/书/绿植的融合摄影。必要文字与图层列表由HTML覆盖，设备本体/阴影使用高保真图。
3. 应用商店台式机完整桌面组合（蓝花、键盘、左侧漂浮卡片），不能继续将素材板中一台设备局部拉伸充当整幅。
4. 统一同一银杯的横幅白底/场景图、杯盖细节、通勤背影、手持近景；新生成素材确保杯盖及杯体特征一致。
5. 六行业横幅完整陈列摄影（3C、女装、男装、食物、饰品、家居），匹配设计里的主体比例及空间。
6. 工具箱的叠图/素材库/全球分发可用可控代码矢量实现的部分由实现角色做；无法达成光影/立体质感的部分补独立高质量资产。不能用简单图标代替高占比装饰画面。
7. 蓝色半透明瓶与光带背景可单独生成无字素材；页面所有营销文案、标题、按钮仍真实HTML，不能以整段设计图/整页截图冒充网页。

## 验收顺序与可接受声明

1. 先在1024 CSS宽下截取上/中/下三段，每段目标高度1536；按上述坐标对齐，最终整页约4608px。首屏轮播固定第一个选中态用于视觉对照，不禁用交互。
2. 优先检查模块边界、标题基线、卡片网格、图片构图。若这些不一致，禁止以“已通过视觉检查”结案。
3. 大框位置偏差目标≤8px，标题字号/行数一致，主要图像主体位置/大小接近；具体像素不可能完全一致时要列明残差，不宣称逐像素复刻。
4. 先完成桌面忠实复刻，再验证1440比例与390响应式。没有手机设计稿，手机版只能称“基于桌面稿适配”，不能称与不存在的手机稿像素一致。
5. 轮播、按钮、焦点等既有可用逻辑可保留，但功能检查不替代同尺寸图像对照。
