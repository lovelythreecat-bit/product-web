# V4 复刻素材报告

角色3：素材补齐。2026-11-04。

已逐张查看 V3 upper/middle/lower 与旧素材板，确认旧版的主要误差不在“缺少照片”，而在于用原素材板重新拼接后构图、人物姿势、工作台细节、图片比例和光感都与已确认图不同。尤其原 `lingling.png` 是全身站姿，V3 首屏是抬手半身；电脑界面、功能矩阵的多层商品/蓝色地球也不是旧素材板可直接替代的画面。

## 实际交付

`standalone/feima-home-v4/assets/manifest.json` 收录 37 个精确视觉区域，坐标基准均为原 1024×1536 图。源图复制为 `design-upper.png`、`design-middle.png`、`design-lower.png`，字节未变。另复制官方透明 Logo 与旧玲玲作为明确标记的备用资源。

没有生成新的近似图，没有修改位图，没有通过 Python 裁剪。使用**原图作为本地 sprite atlas，CSS 只显示纯插图区域**，保留真实 DOM 标题、正文、按钮和交互。不得把完整设计片段或整张卡片作为页面背景。

坐标详见 manifest，不再复述以免出现两个不同版本。

## CSS 使用公式

对于区域 `[x,y,w,h]`，外框比例 `aspect-ratio:w/h; overflow:hidden; position:relative`。内部 source `<img>` 绝对定位：

```js
style.width = `${1024 / w * 100}%`;
style.left = `${-x / w * 100}%`;
style.top = `${-y / h * 100}%`;
// height:auto; max-width:none; position:absolute; display:block;
```

源图固定1024×1536；外框按正确w/h比例显示时对应区域不会变形。固定设计坐标布局也可直接用 background-size:1024px 1536px + background-position:-xpx -ypx；整页统一缩放时比例同步。

首屏人物、工作台使用 manifest clipPath；原背景深蓝/浅蓝可以在最外侧用 CSS mask 羽化，但不改变人物像素，也不遮盖主文案。人物轮廓是人工从参考图定位，最终1024px截图必须检查边界。

插图中少量电脑UI标签、聊天泡泡文字和静态时间线属于画面本身，不是页面正文；其正文与按钮仍必须可选择、可访问。视频图是静态示意，不能据此声称实际视频播放。

## 限制与验收

本方案最大优势是画面与设计稿同源，避免生成近似人物/背景。原图只有1024px宽，放到更大画布不会产生额外清晰度；若以后需要生产级高清素材，应根据这批精确构图逐个生成更大插图，并另行视觉确认。

本角色只补资产与坐标，不编辑页面HTML/CSS/JS。已通过 JSON 解析、37 个矩形边界检查，以及三张源图与原文件 SHA-256 一致性检查。统筹角色需检查首屏蒙版是否覆盖标题/按钮、三段1024基准同尺寸截图和移动响应。未执行浏览器验收。
