# V4 宽屏修订

日期：2026-11-04。实施角色：homepage_v4_wide_revision。用户确认的四项修改优先于此前1024像素固定坐标：首尾铺满、缩小标题、去掉轮播底部进度条、加宽主体。

## 修改

- 移除 `#page-content` 的1440px最大宽度，首屏和页脚直接占满浏览器。底部行动横幅从主体中全幅展开；保留原蓝色配色和素材。
- 桌面导航、首屏内容及主内容使用95%视口宽度，1920px时为1824px，两侧各48px。首屏左右区域改为40%/60%定位，避免右半屏空洞。
- 保留根设计单位的既有上限，不因1920或更宽视口将全页文字继续放大。首屏大标题最高42px，板块标题最高35px；首屏详情标题、引导标题与部分卡片标题同步适度缩小，手机大标题27px、板块标题22px。
- 加宽后，场景、行业、能力、作品和价值卡改为随内容与图片自然增高。图像内部保持manifest矩形比例，不以强制高度拉伸sprite，不露出相邻正文。
- `.tab-progress` 使用 `display:none`，保留元素与原计时JS，避免影响5000ms自动切换、点击重计时和键盘操作。
- 文案、模块顺序、价格、素材来源、配色、独立HTML边界未变。仅改 `styles.css` 与 `README.md`；未改生产系统或部署。

## 检查

`node --check standalone/feima-home-v4/script.js` 通过（JS未改）。浏览器1920/1440/390宽度、图片/文字边界、轮播与页面视觉由主代理独立检查；此报告不提前声称视觉验收通过。

## 主代理实际验收反馈

- 1920px：主体1824px，首屏和页脚均1920px。
- 1440px：主体1368px。
- 390px：无横向溢出。
- 首屏标题桌面42px、手机27px；板块标题桌面35px、手机22px。
- 进度条隐藏正常，自动轮播实测5120ms，手动切换通过。
- 根据1440px截图，轮播卡片小字宽度在801–1699px恢复7em，避免碰右侧图片；仅1700px以上使用10em。此次最后修正仅涉及该文字宽度规则，未改其他布局或JS。
