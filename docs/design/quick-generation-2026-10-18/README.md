- 视频方案使用现有 `VideoTaskPanel.vue` 的只读返回字段：创意方向、目标人群、商品卖点、视频时长、画面比例、字幕、旁白、音乐、视觉描述及镜头内容。时长等为服务返回示例，不是新增表单设置；去掉上版自行概括的“节奏要求／声音”等方案字段。
- 失败处理修正为现有的“保留冻结积分，用户选择重试或释放”；不再默认自动释放再收费。

用户意图：商家只准备一次商品属性与参考图片，依次确认商品、营销文案、图片成果，再生成视频。各阶段由用户确认推进；图片生成前选择内容。成功标准是可以走通整条流程，同时保留对内容和费用的控制。

## 本稿提出的流程

1. **商品确认**：工作台增加“快速生成”入口，进入四步引导。保留商品摘要与“填写／编辑资料”抽屉；按现有商品类型动态展示对应属性，保存生效，取消不保存，Escape 不关闭。参考图可上传、移除；示例中已填入商品，实际新建应为空白或显式复用当前商品。商品编辑必填性沿用现有名称、类型及 Agent 校验；图片阶段再按现有规则检查品类、平台、图片用途与素材。点击“确认商品，生成文案”，居中确认费用再执行。
2. **营销文案**：展示完整文案，可修改、复制，或重新确认费用生成。点击“确认文案，选择图片”只进入下一步，不自动生成图片。用户修改后的确认版本作为后续创作输入；原始生成成果保留，不能改写历史任务快照。
3. **图片生成**：目标平台必选且不代选。可多选“商品主图 1 张”“详情图 3 张”“商品长图 1 张”；默认不选，选齐为 5 张。选择后逐类显示费用，在一张确认框内列清各任务与合计。各类生成任务分别记录结果与结算；详情图三张完整交付，商品长图完整交付一张。生成后停留在成果确认页，可逐张预览，长图预览展示完整成图。点击“确认图片，继续视频”进入第四步。
4. **视频生成**：明确从已上传商品参考图选择首帧，沿用现有素材与首帧校验。确认费用后进入现有视频方案阶段，通过“查看并确认方案”打开只读抽屉，再确认方案出片，不重复收费。完成后汇总文案、图片、视频入口。

推荐在现有工作台内呈现四步引导：左侧任务入口、顶栏与暖色身份继续沿用；中间与右侧组成当前步骤内容和商品／进度摘要。相比长弹窗，独立内容区便于处理图片预览和长文案；相比另建完整应用，保留了工作台上下文。本稿只为快速生成增加该结构，不修改已有单项创作流程。

桌面内容区独立滚动，主要操作固定在面板底部。手机改为单列，保留最近任务选择器及新建入口，操作区按内容顺序位于末尾，不遮挡资料。商品编辑使用全屏抽屉，作品预览使用居中弹窗。

## 返回、失败与继续

- 文案、图片、视频之间通过明确确认推进，没有自动跳过人工审核的开关。
- 可返回上一步；重新确认上游内容后，下游生成使用新版本。已经生成的成果及费用记录保留；本原型不实现完整的跨版本任务管理。
- 提供“保存并退出”，原型只保存本机浏览器草稿。正式版本需将流程阶段、选项、已确认版本及各任务关联保存在服务端，以支持退出后继续。原型刷新恢复不等于服务端恢复已实现。
- 失败示例为“主图已成功、详情图确定失败”：保留已成功项，失败项积分保持冻结。用户可确认使用原冻结积分重试，或确认释放；释放后重新生成须重新确认费用。原报价失效不提交。受理状态不明先核查原任务；结果保存失败先恢复原成果，不能盲目重发。
- 图片未完整确认时不继续视频。用户可在图片完成后保存退出；本稿不另加“跳过文案／跳过图片直接视频”流程。
- 重生成创建新任务并再确认费用，原成果保留。价格变更、余额不足、缺素材等正式错误继续复用现有业务校验与恢复语义。

## 评审时需要确定的设计决定

本稿的图片“选择内容”按选择产物类型解释，主图、详情图、长图可以组合勾选；没有另加长图分段编辑器。图片阶段确认一组任务的费用，各任务独立结算。这些属于待本稿确认的提案，不写入正式设计基准。

本次用户明确提出分步串联创作，扩大了历史需求“首版独立调用、不自动串联”的范围；以本次指令开展原型，本轮按用户要求只核对和修正字段。后续实施需检查文本确认版本向图片／视频传递、批次任务关联、可恢复进度与逐任务计费，不可仅用前端按钮拼接后宣称完成业务功能。
