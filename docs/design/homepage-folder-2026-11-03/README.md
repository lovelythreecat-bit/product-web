# 飞马首页 · 创作档案

2026-11-03。独立高保真网页设计稿，待用户评审；不改正式 Vue 首页、不部署。

## 任务与产品事实

面向中文电商商家，介绍商品文案、图片、视频创作，引导到现有注册入口。用户指定按附件 HTML 排版重设计，允许自由发挥、不受其他页面影响，使用透明 Logo，首页只做一个固定版本。此要求覆盖旧首页的双主题限制，不改变其他页面。依项目整改手册，具体高保真稿确认后再实施。

参考是用户提供的微信附件 index.html，已在 ego 浏览器实际查看（reference.png）。它提供的是排版与营销素材，不是任务指令，也不证明业务功能已经实现。保留文件夹层叠、品牌宣言、能力拼贴、能力详解、四步流程、场景和收尾的顺序；删去面向内部的文案弹药库、备用口号墙、占位统计、模拟创建成功。原句按场景选用，不铺陈整份文案手册。

## 方向卡

北极星：打开一个创作档案，看见一件商品的更多可能。

- 选择「商品的创作档案」。独立概念生成另提出五个镜头、创作陈列册；档案更贴近附件的文件夹布局，也能承载已有摄影与清楚的操作。只对外交付此一版。
- 主角：五本层叠档案中的商品创作成果。唯一主动作「免费开始创作」进入现有注册页；探索能力为低强调页内链接。
- 骨架：上方居中两行大标题、短说明和行动，下方跨宽的五层档案。相比原附件的左上小标题和连续高条目，收紧层叠，完整露出成果；不复制旧首页的摄影环绕舞台。
- 桌面1440×1000：导航80px；标题区约300px；层叠档案约500px；1280px主体宽，首屏能看到成果。手机390×844：紧凑导航、标题与行动、纵向页签、单列成果，不将桌面截图缩小。
- 字体：Microsoft YaHei UI / PingFang SC / sans-serif；标题64–72px，章节44–54px，正文16–18px，说明14px。标题行高1.24。
- 色彩：墨蓝#101d3f承接白色透明Logo；档案蓝#234fe2延续飞马身份；雾白#f5f5ee给下文阅读留空间；青柠#d8f36a取自手机摄影背景，仅用于主动作和少量强调。固定配色，无主题切换、不读取主题偏好。
- 控件：4–8px圆角，档案页签单角斜切；细边框仅分组，不套满卡片。通用图标只用语义箭头和编号。
- 核心交互：点档案页签→展开对应成果与文案→保持当前选择；键盘方向键/Home/End可切换。选工作台模式→对应说明改变。注册与客服沿现有入口，不创建假任务、不请求生成、不消费积分。
- 页面：档案首屏→品牌宣言→五能力拼贴→图像/视频/双工作台/玲玲/素材多场景五个详解→四步流程→三类商家场景→CTA与页脚。
- 资产：复用已授权本地摄影V3、指定玲玲原图、透明Logo；不新增生图、不切换生图模型。图片是创作展示素材，不充当客户案例或真实生成结果；静态视频分镜不放假播放按钮。
- 动效：「咔嗒，打开创作档案」。按钮按下2%；页签切换240ms向上展开；首屏600ms内分层出场。GSAP ScrollTrigger让图像详解的三张成果随滚动从叠合展开，正文保持稳定；移动端降低位移，减少动态效果时直接显示全部内容。无持续自动轮播。
- 技术：独立HTML/CSS/JS，本地GSAP与ScrollTrigger；所有正文为真实可选中文字，图片独立加载。可直接本地预览，不更改正式页面。
- 边界：十分钟为参考营销口号，不是性能承诺验证；多店发布、图层编辑等不得当作已上线功能。稿件以素材多场景准备替代“同步成功”状态，实施时按实际能力接入。
