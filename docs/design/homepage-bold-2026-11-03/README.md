## 视觉与动效

首页属于 Persuade 宣传页面。本稿把原双栏柔和轮播扩展为大标题加横贯首屏的空间商品舞台，继续使用已确认飞马蓝、中文系统字体、完整 Logo 与玲玲原图。字号、舞台比例和装饰轨道属于首页提案，不修改共享 DESIGN.md。

| 区域 | 表现与交互 |
| --- | --- |
| 首屏 | 最高 94px 标题，3 个独立商品画面使用 CSS 透视编排；Canvas 实时绘制 4 条椭圆光轨及运动光段。中央商品有扫描光幕，6.5 秒轮换；可点选品类或在舞台使用左右方向键、Home、End；桌面鼠标有小幅透视反馈 |
| 商品到成果 | 桌面固定舞台随滚动切换同款保温杯的原图、通勤海报、人物口播分镜；点击步骤后由手动操作接管，避免与滚动争夺；手机使用点选步骤 |
| 商品展示 | 大幅鞋服图配美妆、数码双画面，改变页面尺度与浏览节奏；悬停轻微放大 |
| 视频展示 | 横幅人物商品分镜、镜头取景线与缓慢运镜；明确标记“动态分镜示意”，并非真实视频 |
| 玲玲 | 指定角色原图与轨道背景，4 个步骤切换陪练提示；入口新窗口打开已有 AI 客服页 |
| 工作台与分发 | 小白／专业介绍可切换；保温杯贯穿描述与结果；素材分发路径沿线运动，未模拟真实发布成功 |
| 结束行动 | 大字号收尾与蓝色主行动，呼应首屏轨道 |

运动预算：Canvas 仅首屏可见且页面在前台时运行，像素比最高 1.5；无动画库、WebGL 或新增依赖。非必要循环离屏／后台暂停，全局暂停按钮可停用循环。系统减少动态效果时保留静态构图、点选步骤与短状态反馈；自动轮换、扫描、运镜与光轨运动停用。此处是 **CSS 空间变换＋Canvas 二维投影**，不声称实时 3D 商品模型或 WebGL 渲染。
