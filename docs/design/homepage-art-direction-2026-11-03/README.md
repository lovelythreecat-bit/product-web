## 设计控制

网站界面延续飞马蓝色双主题；图片允许独立的撞色和材质语言，不再把蓝色 UI 解释成所有图片只能是浅蓝色摆拍。主角、前景、中景、背景各有作用，创意元素服务商品和广告主题。手机的相机数量、排列、机身颜色与材质以 source 为参考。白底图仅用于“输入”，不冒充设计成图。

玲玲和完整 Logo 继续引用既有指定素材；公开真实案例仍属于生产接口，本评审稿中的商品及人物均是虚构创作示例。人物图是静态分镜，不代表真实生成视频或真实客户作品。已有营销文案沿用上一版，不作为能力已上线的证明。

手机端顺序沿用现有首页，重点核对中央主图、创作成图与人物脸部／手机裁切。配图展示页在手机上依次单列显示。

## 生成方式与模型记录

使用内置 `image_gen`，每张独立生成；手机后续图使用白底图作产品身份参考。提示词请求沿用用户配置 `gpt-image-2.5`，没有主动切换模型。工具未提供模型选择参数，也未返回实际型号，因此不能独立核验实际生成型号。原图全部保存到本目录三个分组中，完整提示词由各组保存。
