## 风格与视觉层级

面向电商商家的生产工具，以奶油米色背景、陶土橙操作色、暖棕文字、商品摄影和清晰分区形成识别度。商品成果是视觉中心；费用和生成按钮是操作中心。大面积保持浅色，陶土橙集中用于主要操作与选中状态。界面采用简洁网格、细边框、克制阴影和中文无衬线字，避免大量装饰、透明玻璃和渐变。

ui-ux-pro-max 的专业工具简洁风格建议用于层级与组件；本轮配色根据用户明确要求定制，不照搬其他产品的配色结果。布局来自已确认需求。旧原型中的绿色情况属于历史原型作用域，不是本轮高保真图与后续视觉参考的颜色来源。

| 字体 | 中文优先本机无衬线；建议顺序 `Microsoft YaHei UI, PingFang SC, Noto Sans SC, sans-serif`。不要求加载网络字体。正文 14–16px，辅助信息至少 12px；标题 24–30px。 |
| 空间与形状 | 8px 为基础间距；卡片间距 24px；卡片约 14px 圆角，控件约 8px。按钮和输入的可交互高度至少 44px。 |
| 图标 | 同一套线性 SVG 图标，约 18–20px，描边一致；图标按钮有可访问名称，不以 emoji 代替。 |
| 桌面结构 | 左侧会话约 215px，右侧表单约 390–405px，中间成果列伸缩；顶栏约 76px。截图是构图参考，实际用 `minmax(0,1fr)` 等布局约束避免内容挤压。 |
| 图片呈现 | 本例使用 1:1 成果图；实际按成果比例显示，保留完整作品，不以截图中的摄影重绘替代用户结果。上传素材采用独立缩略图。 |
| 状态与动作 | 任务状态与积分结算分开建模。成功卡片提供预览、下载、重新生成、详情；重新生成创建新任务并再次展示费用。 |
| 商品资料 | 默认摘要；点击编辑打开侧边抽屉。保存更新摘要，取消不保存。 |
| 设置与 AI 辅助 | 设置默认摘要，点击原位展开；AI 建议可编辑、采用、取消、撤回，不自动创建生成任务。 |
| 弹层 | 作品预览用居中弹窗；任务详情用只读抽屉；收费与删除用居中确认。生产弹窗与抽屉禁止 Escape 关闭（抽屉按用户 2026-10-18 最新要求）；保留焦点隔离及显式关闭后焦点恢复。 |
| 响应式 | 桌面为主；窄屏改为单列，资料与表单先于结果，历史会话用选择器，保留新建、作品和积分入口。手机抽屉全屏。此图不等于完整手机布局交付。 |
| 动效与可访问性 | 按钮/展开可用 150–200ms 反馈，支持减少动态效果；可见键盘焦点、外部字段标签、贴近字段的错误信息、正文对比度至少 4.5:1。 |

## 图示数值与事实边界

`商品创作台` 是暂定名称。图中的用户、商品摄影、会话、112 积分余额、20 积分报价和 1024×1024 规格都是设计示例，不代表真实账户、定价、Agent 能力或官网授权案例。暖色版的示例商品改为奶油白陶瓷杯，图中名称为「陶瓷马克杯」。真实商品名称、资料和图片由用户提供，真实可用规格与报价由确认后的服务端配置提供。

图片生成可能产生微小文字、间距偏差；落地代码以需求和以上规则保证准确文字、响应式、焦点及操作语义，不直接将整张设计图嵌入界面充当实现。
