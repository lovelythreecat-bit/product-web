## 设计方向

沿用用户提供的完整飞马蓝色图标，不抠图、不重绘。浅色以冷白画布、白色面板和飞马蓝主要操作建立层级；深色采用墨蓝画布、蓝灰面板、浅蓝操作与浅色正文。商品摄影保留自然暖色，与冷色 UI 形成清楚分区。

主题色值由提案的 `home.css` 与 `workspace.css` 定义：浅色画布 #F3F6FB、面板 #FFFFFF、正文 #182843、次要文字 #586B85、主操作 #1559D6；深色画布 #0B1220、面板 #121E32、正文 #EAF1FF、次要文字 #A4B5CE、主操作 #79AAFF。主要操作上文字在两主题分别使用白色和墨蓝，避免机械反色。

首页沿用已确认的“让好商品，亮眼登场。”文案方向。所有准确标题、按钮及模块文案直接登记于可读 HTML；未使用生成图片承载文字。主题、间距、细边框、按钮层级和焦点样式已迁移至登录、作品、个人中心、快速生成与后台，保留这些页面的业务结构。

## 手机顺序

首页依次为品牌与入口、价值说明、商品视觉、创作能力、场景、流程、底部行动。工作台先展示历史选择、资料与设置，再展示成果；固定费用区域保留主要动作。两主题均有 390px 手机稿，不把桌面稿当作手机验收。
