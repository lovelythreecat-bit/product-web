# 创作工作台视觉提案 V1.1

日期：2026-10-17。状态：用户完成两轮细节修改后明确要求代码实现；已落地正式工作台组件。实现与验证见 [实施记录](../../verification/workspace-redesign-2026-10-17.md)。

本次针对整个创作工作台的视觉质感重新设计，保留已确认的 V2 奶油米色、陶土橙、桌面三列、任务化结构及紧凑密度。设计预览取自本地当前工作台的真实静态页面内容；展示数据属于本地页面快照，不作为公开案例或价格配置。

## 设计重点

- 左侧：按用户本轮明确要求取消任务编号，只保留商品名、状态和时间两行；同步缩小图标、上下内边距和圆角。长名称单行省略，悬停与无障碍名称仍保留全文。选中任务用完整细边框、纸白表面和陶土橙图标区建立识别，替换旧的侧边色条。失败与待核查分别标明，任务数量不夸大。手机任务选择器同样取消编号，以时间区分同名任务。任务精确定位链接和中央任务信息保持原有语义。
- 中央：暖灰画布衬托白色成果阅读区，正文限制版心宽度，原文首行只作视觉标题排版，按用户要求使用正常字重，不加粗、不改正文内容。任务身份、状态和详情集中在成果上方，复制、预览、下载与重新生成保持在成果下方。图片及视频后续沿用该画布与工具条，需要补充各自实测。
- 右侧：类型切换固定顶部；商品资料用一组低对比底色承载，名称有明确层级，所有字段与完整内容继续保留；参数与创作指令用分隔和间距组织。费用和生成保持固定底部。
- 外壳：顶栏紧凑选中导航、统一线性图标、低饱和分区、克制阴影；积分区改为精致的底部面板。
- 手机：保留历史任务选择器、商品与表单先于成果的既有顺序；不照搬三列；主要触控范围至少 44px。

## 文件与评阅

`index.html` 是独立静态设计预览，复用页面现有 Element Plus 视觉与样式快照，追加样式在 `workspace-concept.css`；`workspace-concept.js` 仅负责设计示意的图标、排版和提示，不请求后端、不提交任务。点击业务按钮会提示这是设计预览；复制文案可在浏览器允许时使用。

预期实施范围：`ConversationList.vue`、`WorkspaceView.vue`、工作台作用域下的 `AppShell.vue` 样式及 `TaskCard.vue` 的工作台呈现。共用控件及其他页面不随本提案改版；接口、计费、草稿、恢复和任务路由均不改变。

依据：`docs/product-design.md` 最新任务化规则、`docs/ui-remediation-manual-2026-10-13.md`、已确认 V2 视觉参考和本轮用户要求。ui-ux-pro-max 的 Minimalism & Swiss Style 匹配用于网格、功能层级及排版；项目既有暖色、圆角和控件规范优先。Vue 组件关键词检索未命中，实施约束以现有代码与项目控件约定为准。

本稿为用户已确认的视觉依据；静态预览本身不证明业务功能、图片视频状态、辅助功能或生产验收通过，正式组件的实际检查结果单独登记于实施记录。
