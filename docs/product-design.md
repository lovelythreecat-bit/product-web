## 本次布局与语义

| 场景 | 原型规则 | 例外 / 边界 |
| --- | --- | --- |
| 官网 | 浅色留白、两列机制演示、一个主要注册 CTA；能力与使用过程采用横向信息行 | 案例缺真实来源时明确留空，不用模拟结果冒充真实产出 |
| 桌面工作台 | 会话侧栏 + 任务记录 + 创作表单；手动 Agent 选择，参数按能力变化 | 原任务固定 Agent 与输入快照，不随编辑器变化 |
| 手机工作台 | 单列，资料与生成表单先于任务结果；保留顶部主要导航、会话选择器、新建会话和充值入口 | 桌面侧栏隐藏，手机历史选择器读取同一会话集合，导航不改原任务或全账户冻结 |
| 普通状态 | 使用页面内文本与语义标签，不只依赖颜色 | 含输入、冻结与收费承诺的正式提交使用原生 dialog 保护确认焦点 |
| 破坏性 / 收费操作 | 删除、再次收费、价格发布明确确认与取消；保留原成果与账本语义 | 未决生命周期、异常政策、多结果政策在生产启用前禁用 |
| 提示词辅助 | 内联预览，可编辑、采用、取消和撤回 | 不创建任务，不擅定免费次数/重置规则 |
| 后台 | 侧边模块与可横向滚动的数据表；必要诊断可见，私有内容默认隐藏 | 独立授权申请不自动授予内容权限；完整凭据不展示 |
| 原型演示控制 | 独立折叠区域明确标识 | 不进入生产用户流程 |

2026-10-11 按用户“交互统一、点击后再展示具体内容”的要求，原型采用以下呈现规则。保持原有视觉风格和业务语义：

| 操作 | 默认展示 | 点击之后 |
| --- | --- | --- |
| 商品 / 个人资料 | 名称、关键资料与编辑按钮 | 统一侧边抽屉编辑；保存后更新摘要，取消或 Escape 不保存 |
| 生成设置 / AI 辅助 | 当前设置摘要 / 辅助按钮 | 设置原位展开；辅助出现可编辑建议、采用和取消；采用后可撤回 |
| 任务 / 用户 / 积分流水详情 | 列表或摘要 | 统一只读抽屉；输入快照等完整信息继续按需展开 |
| 作品预览 | 作品缩略图与预览按钮 | 居中弹窗；只读操作提供关闭，不出现取消或保存 |
| 正式生成 / 删除 | 操作按钮 | 居中确认；明示费用或删除对象；危险操作使用红色确认按钮 |
| 后台新增 / 编辑 / 配置 / 积分发放 / 官网介绍 | 数据、摘要与操作按钮 | 使用同一套抽屉与表单；字段校验后保存或确认；完成后更新列表 / 流水 |
| 次要说明 / 版本 / 生产门槛 | 精简摘要或说明入口 | 在相关详情、确认框或折叠说明内展示；收费承诺和当前异常仍可见 |

所有弹窗和抽屉共用 `app.js` 的 `openOverlay`；后台 `admin.js` 只适配业务表单。长内容只滚动内容区，标题与操作区固定；手机抽屉占满视口。关闭后恢复触发按钮焦点；打开收费 / 删除确认时默认聚焦取消。页面导航、选择与展开保留各自语义，不把所有按钮都改成弹窗。

## 主题与组件来源

实际数值以 [style.css](prototype/style.css) 的 `:root` 与响应式规则为唯一实现来源。语义如下：纸色背景支持长时间阅读；深绿用于主操作和成功；暖棕用于未结算、待核查与门槛；红用于确定错误。使用文字同时区分状态。白色表单与任务面板采用轻边界，主操作一屏保持清晰。正文用本机中文无衬线字族以支持离线运行，辅助标签不小于 12px。

全局主要按钮最小高度 44px。按钮、输入、选择与链接有可见焦点。标签在控件外可见，错误紧邻字段；模态聚焦取消按钮、允许 Escape，使用原生浏览器焦点隔离。提供减少动态效果适配。长表格在自身容器横向滚动，不使整个页面横向溢出。数字对齐用于账本和表格。

入口为 [index.html](prototype/index.html)，交互渲染 [app.js](prototype/app.js)，本地会话/任务/作品/账户模型 [model.js](prototype/model.js)，既有官网/认证/后台展示 [views.js](prototype/views.js)。原任务只读提交快照；草稿按会话保存，参数按Agent保存；正式成果与流水通过task_id关联。所有资源同目录且不依赖网络，没有建立业务组件库或更改正式技术方向。
