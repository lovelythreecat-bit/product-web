# 回滚

本步未执行回滚；须在 T24 指定隔离环境批准后演练。先用原发布 SHA、migration head 与备份版本清单确认兼容性，保留当前失败实例证据。

只有旧镜像与当前数据库向后兼容且已验证时，才能切换应用镜像/digest。`PERSISTENT_ROOT` 始终不变，不在发布目录存放文件。禁止为回滚删除卷、重建数据库、执行 downgrade 或清理持久文件。数据库不兼容时进入 recovery 流程，在新隔离目标恢复并核对，不覆盖现场。

回滚不重建平台任务、外部提交标识、账本冻结或作品身份。不能把 Redis 重投当作重新请求生成；已有上游 ID 查原任务，未知受理留核查，保存恢复只保存原成果。当前生产 Agent 未接入，不能靠重启解除其门禁。

切换前后记录 release SHA、迁移 head、时间与批准引用；运行 GET smoke 和只读 reconcile，比较 Outbox、核查期限、保存恢复、终态与账本差异。只读核对出错时不要修账，升级给业务和技术负责人。未获 D12 恢复/公开批准不得开启入口。
