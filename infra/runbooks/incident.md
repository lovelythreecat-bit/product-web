# 事件响应

根据 trace UUID / task UUID 定位受限运维日志；不在聊天、工单或普通日志复制输入素材、上游 URL、令牌、数据库 dump 或账号余额明细。监控脚本输出只含聚合数量及固定差异码。

| 信号 | 只读确认与处置方向 |
| --- | --- |
| Outbox 积压、最老到期年龄增长 | 查 MySQL/Redis 可达性、worker 运行状态；消息只是唤醒提示，不直接重发生成 |
| investigation_overdue | 分配核查责任并按批准政策处理；期限届满不是失败证据，不释放冻结 |
| SAVE_RECOVERY / 保存到期年龄 | 检查磁盘、持久根挂载、原 save manifest 和文件摘要；恢复原成果，禁止新生成 |
| ledger_mismatch | 保存聚合差异码并暂停后续人工结论；交账本负责人核验，reconcile 不改账、不改任务、不改冻结 |
| 磁盘余量、预算含预留占比告警 | 按 D12/D07 申请容量，不删除共享文件或历史，不以隐藏作品推断物理容量已释放 |
| public_cleanup_pending | 确认 API 已拒绝公开；物理清理可能尚未完成，仍纳入备份与核对，不手工将状态改回 published |
| 监控退出 1 或阈值未配置退出 3 | 视为监控盲区，检查只读连接与 D12 配置；不当作“零差异” |

成本未知显示 unavailable。HTTP/任务阶段耗时不等于供应商成本。终态成功率统计为全部持久任务，没有终态时为 null。

故障注入、停服务、迁移/回滚、备份/恢复、公开切换均需对应隔离演练或明确部署授权。本工具不清历史，不 FLUSH Redis，不删除卷。故障期间保留现场，必要时走恢复手册，以隔离目标验证后再决定业务恢复。RPO/RTO 与升级时限由 D12 指定，本文不代签。
